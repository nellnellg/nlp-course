# NLP Course

Apps I built for my natural language processing course.

## Chapter 2

**Teach Beep to Read.** A kid friendly walkthrough of the chapter 2 notebook. Beep the robot learns to read a runner's note in six steps: cutting text into pieces, skipping stop words, stemming, lemmatizing, tagging parts of speech and finding names. Every result comes from running NLTK on my own paragraph.
